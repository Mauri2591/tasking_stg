Match aproximado por PALABRA COMPLETA contra vendorProject + product.

public buscarPorNombre(string $nombreVulnerabilidad[, int $maxResultados = 3 ]) : array<string|int, mixed>

Reglas anti-falsos-positivos:

  • Se descarta el contenido entre paréntesis antes de extraer palabras (suele ser un ID de advisory, ej: "(SA-CORE-2024-007)", no aporta).
  • Si hay 1 sola palabra clave útil, alcanza con que matchee esa.
  • Si hay 2+ palabras clave, se exige que coincidan AL MENOS 2, para evitar que una sola palabra genérica (ej: "agent") arrastre coincidencias casuales sin relación real con la vulnerabilidad.

generarContextoVerificado()

CisaKevChecker.php : 188

Cruza un array de vulnerabilidades (formato de extraerVulnerabilidadesXlsx) contra el catálogo KEV y devuelve un bloque de texto formateado, listo para inyectar como contexto verificado en el prompt de la IA.

public generarContextoVerificado(array<string|int, mixed> $vulnerabilidadesXlsx) : string

Prioridad de match por cada vulnerabilidad:

  1. Si el nombre trae un CVE explícito (ej: "... (CVE-2024-7347)") → match exacto.
  2. Si no, se intenta match aproximado por nombre de producto/vendor.
  3. Si no hay ninguna coincidencia, se omite (no se inventa relación).
